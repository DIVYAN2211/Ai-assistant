# SenseRoute - AI Virtual Assistant by Divya Nagaraj

## About
This project is a personalized AI assistant built using React.js and the Gemini API. It features custom functionalities, including website launching, city weather fetching, time display, and Google search.

## Features
- React.js & Gemini API-based.
- Custom responses for various user tasks.
- Ability to open websites.
- Weather information for cities.
- Current date and time display.
- Google search functionality.
